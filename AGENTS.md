# AGENTS.md — instructions pour les agents travaillant sur ce dépôt

## Début de session

Avant tout travail, lire la documentation du projet :

- `docs/` — vue d'ensemble succincte du projet ;
- `spec/` — spécification complète et autonome (protocole, architecture, commandes, sécurité, tests, structure) ;
- `ROADMAP.md` — feuille de route (une PR indépendante et testable par étape).

## Avant chaque PR

Mettre à jour la documentation (`docs/`, `spec/`, `ROADMAP.md`) pour qu'elle reflète les changements de la PR.
